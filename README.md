# Tarea 4 - Desarrollo Web
   
## Descripción
Esta tarea incluye la implementación de una app web, usando Spring Boot y el patrón de Modelo - Vista - Controlador.

Tuve problemas con las migaración del apartado de destalles de listado. Al clickear sobre uno de los avisos del listado, no pude lograr que se renderice correctamente el aviso detallado.

También tuve problemas con realizar las validaciones del lado del servidor para los nuevos avisos.


Para la parte de los gráficos, se usó la librería de Highcharts.
https://www.highcharts.com
También, después de la migración, el primer gráfico presentó problemas.

Sin embargo, la nueva función de calificar los avisos se encuentra implementada. En la parte del listado de avisos, se agregaron 2 columnas nuevas, tal como se solicitó: La primera calcula el promedio de las notas que tiene cada aviso, dejando el resultado con 1 decimal; la segunda nueva columna es para agregar una nota, en la que puedes seleccionar una nota del 1 al 7 y, al seleccionar una opción, guarda el valor seleccionado y recalcula el valor del promedio.
