# Tarea 3 - Desarrollo Web
   
## Descripción
Esta tarea incluye la implementación de una app web, usando Flask, HTML, JS y CSS.

No pude implementar la parte del zoom de las fotos, en el apartado de el aviso particular.

Se considera para la validación en el lado del servidor, que el usuario no demorará más de 2 horas en hacer el formulario.
